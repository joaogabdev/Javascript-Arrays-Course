# JavaScript Arrays

Repository created while studying JavaScript arrays through Alura.

This repository contains my exercises and notes from the course. The code was written by me as part of my learning process.

## 📚 Topics Covered

- Creating and manipulating arrays
- Adding and removing elements
- Updating array elements
- Accessing and searching arrays
- Array destructuring
- Cloning arrays
- Splitting and joining arrays
- Nested arrays
- Iteration
  - `for`
  - `for...of`
  - `forEach()`
- Array methods
  - `map()`
  - `filter()`
  - `reduce()`
- `Set`
- Calculations with arrays
- Working with arrays of data

## 📂 Repository Structure

The repository contains practical exercises covering different concepts related to arrays in JavaScript:

- `adicionar-nota.js` — adding elements to an array
- `array-arrays.js` — working with nested arrays
- `atualizar-lista.js` — updating array elements
- `calculo-media.js` — calculating averages
- `clonar.js` — cloning arrays
- `desestruturar.js` — array destructuring
- `dividir-array.js` — splitting arrays
- `excluir-elementos.js` — removing elements
- `filtrar.js` — filtering array elements
- `for-classico.js` — iterating with a classic `for` loop
- `for-of.js` — iterating with `for...of`
- `foreach.js` — iterating with `forEach()`
- `juntar-salas.js` — joining array data
- `map.js` — transforming array elements with `map()`
- `map-strings.js` — using `map()` with strings
- `media-for.js` — calculating averages with loops
- `procurar-em-lista.js` — searching for elements in an array
- `reduce.js` — reducing array values with `reduce()`
- `set.js` — working with `Set`
- `ex1.js` / `ex2.js` — additional exercises
